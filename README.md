## Real-time Click Tracking & Analytics Dashboard

Track, visualize, and analyze user click behavior in real-time with this interactive Streamlit application.

### ✨ Features

- **Real-time Click Tracking** - Every click is captured instantly
- **Interactive Dashboard** - Live metrics and visualizations
- **Session Management** - Track user sessions uniquely
- **Advanced Analytics** - Heatmaps, funnels, and engagement metrics  
- **Data Export** - Download reports as CSV
- **User Activity Monitoring** - Individual user journey tracking
